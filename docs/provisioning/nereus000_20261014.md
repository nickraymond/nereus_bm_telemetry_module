## Findings for the next unit

1. `provision_lte.sh` step 4 stops NetworkManager. On this host that **removed wlan0's IP for ~35 s** (eth0 kept its address). Run it detached with a log (as above), from Ethernet if you can, so a dropped ssh cannot kill it while MM and NM are stopped.
2. ModemManager 1.24 marks the Spotter consoles (STM32 CDC-ACM) as modem candidates. Install the udev ignore rule **before** ModemManager on any host that also has Spotter consoles.
3. The Tailscale auth URL is good for ~5 min. Hand it over right away; on `http 410` re-run `tailscale up` for a new one.
4. The Wi-Fi firmware crash during the apt install is unexplained (single event). If it recurs, check `sudo dmesg | grep brcmf` and look at RF/power next to the HAT.
